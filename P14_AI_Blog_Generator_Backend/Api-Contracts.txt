AI Blog Generator - API Contract:

1. Authentication APIs:

1.1 Register:

Endpoint: 			POST /api/auth/register
Authorization:			Public

Request:
{
  "userName": "johnsmith",
  "email": "john@example.com",
  "password": "Password@123"
}


Success Response (201 Created):
{
  "message": "User registered successfully.",
  "accessToken": "<jwt-token>",
  "refreshToken": "<refresh-token>",
  "expiresIn": 3600,
  "user": {
    "userId": 1,
    "userName": "johnsmith",
    "email": "john@example.com",
    "role": "User",
    "availableCredits": 100
  }
}


Error Responses:


400 Bad Request:

{
  "message": "Validation failed.",
  "errors": {
    "email": ["Email is already registered."]
  }
}


409 Conflict

{
  "message": "Username already exists."
}


1.2 Login:

Endpoint:			  POST /api/auth/login
Authorization:		          Public


Request:
{
  "email": "john@example.com",
  "password": "Password@123"
}


Success Response (200 OK):
{
  "accessToken": "<jwt-token>",
  "refreshToken": "<refresh-token>",
  "expiresIn": 3600,
  "user": {
    "userId": 1,
    "userName": "johnsmith",
    "email": "john@example.com",
    "role": "User",
    "availableCredits": 95
  }
}


Error Responses:

401 Unauthorized:

{
  "message": "Invalid email or password."
}



1.3 Refresh Token

Endpoint:			POST /api/auth/refresh-token
Authorization:			Public

Request:
{
  "refreshToken": "<refresh-token>"
}


Success Response:
{
  "accessToken": "<new-access-token>",
  "refreshToken": "<new-refresh-token>",
  "expiresIn": 3600
}


Error:
{
  "message": "Refresh token is invalid or expired."
}


1.4 Logout

Endpoint:			POST /api/auth/logout
Authorization:			User

Request:
{
  "refreshToken": "<refresh-token>"
}


Success Response:
{
  "message": "Logged out successfully."
}


2. Profile APIs:

2.1 Get Profile:

Endpoint:			GET /api/profile
Authorization:			User


Request:			None


Success Response:
{
  "userId": 1,
  "userName": "johnsmith",
  "email": "john@example.com",
  "profilePictureUrl": "https://...",
  "availableCredits": 95,
  "role": "User",
  "createdAt": "2026-07-21T10:30:00"
}



2.2 Update Profile:

Endpoint:			PUT /api/profile
Authorization:			User

Request:
{
  "userName": "John Smith"
}


Success Response:
{
  "message": "Profile updated successfully."
}



2.3 Upload Profile Picture:

Endpoint:			POST /api/profile/upload-picture
Authorization:			User

Request:			multipart/form-data

profilePicture : 		File

Success Response :
{
  "message": "Profile picture uploaded successfully.",
  "profilePictureUrl": "https://..."
}



2.4 Delete Profile Picture:

Endpoint:			DELETE /api/profile/picture

Success Response:
{
  "message": "Profile picture removed successfully."
}



2.5 Delete Account:

Endpoint:			DELETE /api/profile
Authorization:			User


Request:
{
  "reason": "No longer using the application."
}


Success Response
{
  "message": "Account deleted successfully."
}
