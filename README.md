# 🚀 AI Blog Generator

An AI-powered blogging platform that enables users to generate, regenerate, expand, shorten, and manage blogs using AI. The application features secure authentication, a credit-based system, Stripe payment integration, and an admin dashboard for platform management.

---

## ✨ Features

### 👤 User
- 🔐 Register & Login
- 🤖 Generate AI Blogs
- 🔄 Regenerate Blogs
- 📖 Expand Blogs
- ✂️ Shorten Blogs
- 🖼️ Generate AI Images
- 📚 View My Blogs
- 🗑️ Delete Blogs
- 📄 Download Blogs as PDF
- 📋 Copy Blog Content
- 💳 Credit-Based Usage System
- 💰 Purchase Credit Plans
- 👤 View & Update Profile
- 🖼️ Upload Profile Picture
- 💬 Submit Feedback & Raise Issues
- 🚪 Logout

### 👨‍💼 Admin
- 📊 Dashboard Overview
- 👥 Manage Users
- 📝 View All Blogs
- 💳 View Payments
- 📩 View Feedback & Issues
- ✅ Resolve User Queries
- 📋 View Deleted Accounts
